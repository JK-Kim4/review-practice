# 요구사항 — 감상 연습장 v2

디자인 목업(`docs/design/mockup/`, [캔버스](https://claude.ai/artifact/D1Ph3qUhQv8Q7WM2fsepK4)) 기준으로 정리한 요구사항입니다.
v1 초안에서 쓰지 않는 기능은 모두 걷어내고 **"감상 남기기" 한 가지 흐름**만 남깁니다.

## 1. 범위

| 남기는 것 | 걷어내는 것 (v1) |
| --- | --- |
| 감상 남기기: 분류 선택 → 포착 · 질문 · 정리 → 읽기 | 4주 루틴, 요일별 루틴, 타이머 |
| 나의 감상 목록과 분류 필터 | 남은 질문 모음 페이지, 가이드·추천 도서 페이지 |
| 이어 쓰기 (작성 중인 감상) | 7종 연습 유형 (→ 세 단계로 통합) |
| Markdown 내보내기, 삭제 | 포스터 업로드, 자기 점검 체크, 같은 작가 기록 비교 |

## 2. 화면별 요구사항

### 2.1 홈 (`Main`)
- H-1 상단: 로고(“감상 연습장”)와 전체 기록 수(`기록 N편`).
- H-2 오늘 날짜(“10월 26일 월요일”)와 제목 “오늘 본 것을 잊기 전에 남겨볼까요?”.
- H-3 메인 버튼 **감상 남기기** → 분류 선택 화면.
- H-4 작성 중인 감상이 있으면 가장 최근 것 하나를 **이어 쓰기** 카드로 보여준다. 문구: “`작품명` · `단계` 단계에서 멈췄어요”. 누르면 멈춘 단계로 이동.
- H-5 **나의 감상** 목록: 최신 관람일 순. 행마다 일(크게)·연월, 분류 배지, 작품명, 발췌 한 줄. 작성 중이면 발췌 자리에 “작성 중 · 단계”를 표시.
- H-6 분류 필터: 전체 · 공연 · 전시 · 책 · 박람회·기타.
- H-7 기록이 없으면 빈 상태 문구를 보여준다.

### 2.2 분류 선택 (`Category`)
- C-1 닫기(✕) → 홈.
- C-2 분류 카드 4종(공연 / 전시 / 책 / 박람회·기타), 아이콘 + 예시 문구. 하나를 고른다(기본: 공연).
- C-3 작품명(필수), 관람일(기본 오늘), 장소(선택).
- C-4 **작성 시작** → 감상을 만들고 포착하기 단계로 이동. 작품명이 비면 안내.

### 2.3 작성 (`Capture` · `Question` · `Compose`)
공통
- W-1 헤더: 닫기(✕) → 홈, 분류 배지 + 작품명, 저장 상태(“저장 중…”, “저장됨”).
- W-2 단계 탭 **1 포착하기 · 2 질문하기 · 3 정리하기**. 언제든 오갈 수 있다. 현재 단계는 저장되어 이어 쓰기에 쓰인다.
- W-3 입력은 멈추면 자동 저장. 탭 이동·닫기 직전에도 저장.
- W-4 막연한 감정 표현(“좋았다”, “슬펐다”, “인상적이었다” 등)을 쓰면 “한 걸음만 더” 안내를 띄운다.

포착하기
- P-1 제목 “무엇이 남았나요?”, 안내 “해석하거나 평가하지 말고…”.
- P-2 분류별 힌트 칩 (공연: 대사·표정·침묵·움직임·조명·무대 구성 / 전시: 색채·재료·형태·크기·배치·빛 / 책: 문장·대목·인물의 선택·장면·제목 / 박람회·기타: 공간·사람들·물건·소리·가장 오래 머문 곳).
- P-3 장면 1·2·3 입력 (3은 선택). 포커스된 카드는 강조색 테두리.
- P-4 **예시 보기**: 〈갈매기〉 예시를 보여준다/숨긴다.
- P-5 **다음 · 질문하기**.

질문하기
- Q-1 제목 “왜 그 장면이 남았을까요?”.
- Q-2 포착한 장면 중 하나를 고른다(라디오). 포착한 장면이 없으면 포착하기로 돌아가라는 안내.
- Q-3 질문 5개: 기억에 남은 이유 / 가장 크게 느낀 감정 / 예상과 달랐던 부분 / 이어지는 내 경험이나 생각 / 아직 남아 있는 질문. 모두 선택 입력.
- Q-4 감정 칸에 막연한 표현이 있으면 **‘왜?’ 한 번 더 묻기** 버튼 → “왜 그렇게 느꼈을까?” 칸이 추가된다(최대 3개).
- Q-5 **이전** / **다음 · 정리하기**.

정리하기
- S-1 제목 “한 편으로 정리하기”.
- S-2 글 제목 + 네 칸: 도입(1~2문장) · 묘사(2~3문장) · 감상(3~5문장) · 마무리(1~2문장).
- S-3 글자 수 진행 막대 `N / 300자`.
- S-4 **내가 적은 재료** 패널: 포착·질문 단계에서 적은 내용. 누르면 마지막으로 포커스한 칸(없으면 도입)에 들어간다.
- S-5 **감상 완료** → 상태를 완료로 바꾸고 읽기 화면으로. 본문이 비어 있으면 안내.

### 2.4 감상 읽기 (`Detail`)
- D-1 뒤로(목록), **수정**(정리하기로), **내보내기**(Markdown 파일), 삭제(확인 후).
- D-2 분류 배지, 관람일 · 장소, 작품명, 글 제목, 본문(칸마다 문단).
- D-3 **남은 질문** 상자 (질문하기의 마지막 답이 있을 때).
- D-4 **이 감상의 재료 보기** (접기): 포착·질문 답 목록.

## 3. 데이터

- 데이터베이스 없이 감상 1편 = JSON 파일 1개: `data/reviews/<id>.json`.
- 저장은 임시 파일 기록 후 교체(rename). 같은 파일에 대한 쓰기는 순서대로 처리.

```json
{
  "id": "a1b2c3d4e5f6",
  "category": "performance | exhibition | book | fair",
  "title": "갈매기", "date": "2026-10-20", "venue": "명동예술극장",
  "status": "draft | done",
  "stage": "capture | question | compose",
  "capture": { "scene1": "", "scene2": "", "scene3": "" },
  "question": { "scene": "scene1", "reason": "", "emotion": "", "whys": [], "unexpected": "", "experience": "", "remaining": "" },
  "compose": { "title": "", "intro": "", "describe": "", "reflect": "", "closing": "" },
  "createdAt": "…", "updatedAt": "…", "completedAt": null
}
```

## 4. API

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| GET | `/api/meta` | 분류·힌트·질문·정리 칸·예시 등 화면 문구 |
| GET | `/api/reviews` | 목록 (최신 관람일 순) |
| POST | `/api/reviews` | 새 감상 (분류, 작품명, 관람일, 장소) |
| GET | `/api/reviews/:id` | 한 편 |
| PATCH | `/api/reviews/:id` | 부분 수정 (`capture`·`question`·`compose`는 칸 단위 병합) |
| DELETE | `/api/reviews/:id` | 삭제 |
| GET | `/api/reviews/:id/export.md` | Markdown 내보내기 |
