# 감상 연습장 (review-practice)

공연·전시·박람회·책을 보고 느낀 것을 **짧게라도 정리해 아카이빙**하기 위한 로컬 웹앱입니다.
"무엇을 써야 할지 모르겠다"는 막막함을 줄이기 위해, 감상문을 바로 쓰기보다
**포착하기 → 질문하기 → 발전시키기** 순서로 감상의 소재를 먼저 모으도록 돕습니다.

데이터베이스 없이 모든 기록을 `data/` 폴더의 파일로 저장합니다.

## 실행

```bash
npm install
npm start
# http://127.0.0.1:3000
```

| 환경 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `3000` | 서버 포트 |
| `HOST` | `127.0.0.1` | 다른 기기에서 접속하려면 `0.0.0.0` |
| `DATA_DIR` | `./data` | 기록을 저장할 폴더 (예: 클라우드 드라이브 폴더) |

테스트: `npm test`

## 기능

- **관람 기록**: 작품명 · 종류(공연/전시/책/박람회) · 관람일 · 장소 · 작가·제작진 · 태그 · 메모 · 포스터/티켓 이미지
- **연습** (모두 자동 저장, 타이머와 〈갈매기〉 예시 제공)
  - 포착하기 — 기억나는 장면 세 가지 (감상 대신 사실부터)
  - 질문하기 — 한 장면에 질문 다섯 개
  - 발전시키기 — '왜?' 세 번 묻기
  - 기본기 — 관찰·감정·해석 분리, 관람 직후 5분 기록, 감상 발견 연습장, 객관적 묘사 다섯 문장
- **짧은 감상문**: 도입(1~2문장) → 묘사(2~3문장) → 감상(3~5문장) → 마무리(1~2문장)
  - 200/300/400/500자 목표와 진행 막대, 구역별 문장 수
  - 연습 기록에서 문장을 골라 각 구역에 바로 넣기
  - "좋았다", "인상적이었다"처럼 피상적으로 끝나는 표현 알림
  - 자기 점검: 구체성 · 자기 이해 · 질문의 발견
- **오늘**: 월·수·금 루틴, 이번 주 기록 현황, 4주 감상 아카이빙 루틴
- **남은 질문**: 연습 중 적은 질문을 한곳에 모아보기
- **같은 작품·작가의 다른 기록**: 예전 감상과 비교하기
- **Markdown 내보내기**: 작품별 기록을 `.md` 파일로 받기
- **가이드**: 훈련 방법, 감상문 구조와 예시, 추천 도서·영상

## 데이터 구조

```
data/
├── works/<id>.json   # 작품 1개 = 파일 1개 (기본 정보 + 연습 기록 + 감상문)
├── uploads/          # 포스터·티켓 이미지
└── settings.json     # 4주 루틴 시작일
```

파일은 임시 파일에 먼저 쓴 뒤 교체하는 방식으로 저장해 중간에 끊겨도 깨지지 않습니다.
`data/`는 기본적으로 `.gitignore`에 포함되어 있습니다. 기록까지 저장소에 함께 보관하려면 `.gitignore`에서 해당 줄을 지우세요(공개 저장소라면 주의).

## 구조

```
server.js            Express 서버와 REST API
src/store.js         파일 기반 저장소
src/exercises.js     연습 유형, 감상문 구조, 루틴 정의
src/resources.js     추천 도서·자료
src/markdown.js      Markdown 내보내기
public/              화면 (프레임워크 없는 HTML/CSS/JS)
test/                API 테스트 (node:test)
```

연습 질문이나 루틴을 바꾸고 싶다면 `src/exercises.js`만 수정하면 됩니다.
